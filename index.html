Remy AI

Remy AI is an AI-powered assistant designed to simplify administrative work, improve task organization, and support everyday business workflows.

01 · PROBLEM ADDRESSED

Daily operations get fragmented across tasks, schedules, messages, and follow-ups — making it hard to stay organized.

02 · SOLUTION & VALUE

One assistant that brings chat, tasks, calendar, approvals, inbox, documents, and follow-ups together — with human approval kept for actions that need it.

03 · FEATURES IMPLEMENTED

  • Conversational AI assistance
  • Task organization and tracking
  • Workflow support across chat, tasks, calendar, inbox, and documents
  • Approval-based actions for sensitive steps
  • Administrative productivity features including follow-ups and activity
  • Web application functionality, live and deployed
  • Android application availability

04 · TECHNOLOGIES USED

AI-assisted development with OpenCode and Codex. AI model access via Groq. Source control on GitHub. Web deployment on Netlify.

05 · MY CONTRIBUTION

Built and integrated the AI-powered product: translated requirements into features, refined prompts and interface iteratively, managed code on GitHub, tested and deployed the web app, and documented the design system and approval-aware patterns.
